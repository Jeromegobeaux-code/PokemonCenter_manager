# The pokemonCenter Manager
Un centre pokemon mais IRL
 
> **Contexte :** un project en SPRING MVC avec Thymleaf créer pour découvrir les fondamentaux du framework
 
## Pitch
 
Imaginez vous pouvoir prendre soin de votre équipe de pokémon et commander des objets de soin où que vous soyez. Grâce à PokemonCenter Manager, ce rêve est maintenant réalité
 
## Fonctionnalités prévue pour cette application
 
- **Possibilité de créer un compte** : l'utilisateur pourra soit se connecter en tant que dresseur soit en tant que menbre du staff, avec des authorisations différentes
- **Dresseurs** : Consulter son équipe, ajouter ou retirer des membres, acheter des objets
- **Staff** : Voir tout les pokemons enregistrés et soigner les blesser, gérer les stock d'objet
